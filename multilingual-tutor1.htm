💡 如何免費取得並設定 Gemini API Key？
  1. 前往 Google AI Studio 並使用你的 Google 帳號登入。
  2. 在左側選單或首頁點擊 Get API key（取得 API 金鑰），建立一組新的 API Key。
  3. 點擊該金鑰旁的 Copy（複製） 圖示。
  4. 回到本頁上方輸入框，按滑鼠右鍵選擇 貼上（或使用快捷鍵 Ctrl+V / Cmd+V），再按 儲存金鑰 即可開始使用。
🔒 給你的簡單安全小提醒
  • 你的 API 金鑰就像家裡鑰匙，只會保存在你現在這台裝置的瀏覽器裡，不會傳到我們的網站主機，也不會寫進這個網頁檔案中。
  • 請使用你自己的 Google 帳號申請金鑰，不要使用別人提供的金鑰，也不要隨便把金鑰截圖或貼給他人看。
  • 如果是在學校、圖書館或借用別人的電腦／手機使用，離開前請記得按一下旁邊的「清除」按鈕，把金鑰從這台裝置移除。
