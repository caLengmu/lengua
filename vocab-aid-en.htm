1 分鐘免費申請 Google Gemini API Key 教學

免綁信用卡、完全免費額度，打造個人專屬 AI 單字庫

1 前往 Google AI Studio 官方網站

使用您的個人 Google 帳號（建議使用私人 `@gmail.com` 帳號，部分學校教育版帳號可能會由網管關閉 API 權限）登入：
https://aistudio.google.com/app/apikey

2 點擊「Create API key」產生金鑰

進入頁面後，點擊右上角或畫面中央藍色的 「Create API key」 按鈕，選擇或建立一個預設專案，系統就會立刻產生一串以 AIzaSy... 開頭的金鑰，點擊「Copy」複製起來。

3 貼回本網頁的「設定 API」視窗即可使用！

點擊本網頁右上角的「設定 API」，將複製的金鑰貼上並儲存。之後您每次輸入單字或編寫故事，都會透過您自己的免費額度直接連線 Google AI。

為什麼老師可以把這個網頁放在網路上給全班用，卻不會爆流量？

因為本程式採用 BYOK（Bring Your Own Key，自帶金鑰） 設計！程式碼裡面沒有寫死老師的 API Key。每位同學打開網址後填入自己的免費 API Key，金鑰只存在同學自己的手機瀏覽器裡，各自使用各自的免費額度，因此全班 100 人同時使用也完全不會消耗老師的額度！
