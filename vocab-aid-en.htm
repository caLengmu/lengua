如何免費申請個人 Google Gemini API Key？

💡 零成本學習： Google AI Studio 提供免費額度（Free Tier），不需要綁定信用卡即可申請，足夠每天生成數十個單字速記短句與故事！
  1. 前往 Google AI Studio 官方網站：
    點擊開啟 https://aistudio.google.com/app/apikey 并登入您個人的 Google 帳號（建議使用個人 @gmail.com 帳號，部分學校網域帳號可能關閉此權限）。
  2. 點擊「Create API key」按鈕：

    若是第一次使用，勾選同意服務條款後，點擊右上角藍色的 「Create API key」，選擇建立在新的專案（Create API key in new project）即可。

  3. 複製並貼回本學習助理：

    畫面會出現一串以 AIzaSy... 開頭的金鑰，點擊「Copy」複製後，回到本網頁右上角點擊 「設定 API」 貼上並儲存就完成了！

給老師與同學的安全提醒：

請勿將您個人的 API Key 公開貼在網路論壇或寫死在公開的 HTML 原始碼中。每位同學各自申請並填入自己的瀏覽器，就能各自享有獨立的免費額度，不會互相佔用流量！
